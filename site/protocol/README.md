# Protocol entry point

This self-contained static entry point is capable of being mounted at
`/protocol` by any gateway. It has no runtime build, account, analytics,
tracking, remote font, or JavaScript dependency.

It is staging material and is not itself deployment or activation evidence.
The repository's normative protocol and release evidence identify generation
0.8.0 as deployed and active under a pinned threshold-signed release authority.
This static page does not implement or claim app-repository submission,
registry receipts, catalog hosting, discovery, or download.

`protocol.json` is the versioned staging status document
`tohseno.protocol-page/2`; it does not reinterpret the released `/1` shape.
