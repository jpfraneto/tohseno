# Tohseno web asset kit

A reusable visual kit for the new **permissionless distribution for Apple software** direction.

## Recommended page hierarchy

1. Hero — distribution first
2. Live network ticker
3. Network stats
4. Apps moving through Tohseno
5. Featured apps / registry
6. Built for the Apple ecosystem
7. How it works
8. Public receipts / protocol
9. Join the network

## Important framing

Tohseno should feel like a living Apple-software network, not an anti-App-Store campaign. The App Store is Apple's curated marketplace; Tohseno is an open distribution network. Lead with software moving between people, then explain infrastructure.

## Folders

- `brand/` — ensō, wordmarks, favicon, app icon
- `mascot/` — canonical portrait and website-ready composite crops
- `app-icons/` — illustrative registry app icons
- `flow-icons/` — build / publish / share / verify-install
- `protocol-icons/` — authority / registry / claims
- `system-icons/` — mac / iPhone / Xcode-like / account / source
- `ornaments/` — orbit lines, sparklines, grain textures
- `social/` — OG and X cards
- `css/` — design tokens
- `references/` — the three visual-direction boards + original mascot source
- `preview/` — one-page asset browser

SVGs are preferred for UI. PNGs are included for quick drop-in use. No font files are included; use the system font stack in `css/tokens.css`.
