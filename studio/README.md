# TOHSENO Studio

Studio is the loopback-only visual surface for the recording loop:

- **Apps** lists local app folders and their recorded Versions.
- **New app** initializes or adopts a folder and adds its `.tohseno/` history.
- **Versions** records the selected folder's current files with an optional
  note.
- **Open folder** hands the app back to the user's normal filesystem tools.

Studio does not choose a coding agent, run inference, build an app, or install
it. Those activities can happen independently; TOHSENO records their results.
