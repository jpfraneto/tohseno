# TOHSENO — Shot 1 intention

Create the first TOHSENO Apple companion app through the ordinary public
factory path. It is historically first and has no protocol privilege.

## Purpose

Give a builder a calm, Apple-native place to understand and act on the identity
and provenance already present beneath the TOHSENO creation experience.

The app works locally without an Anky, Inc. server. It has no username,
password, mandatory account, telemetry, tracking, or global cross-app user
identity.

## Useful first screen

Open directly to a useful overview with these human-readable sections:

- **Your identity** — BuilderID, recovery state, and whether it is still local
  or has been witnessed publicly.
- **This iPhone** — the app-specific InstallationKey and its local status.
- **Devices** — authorized Builder DeviceKeys, with this device or Mac clearly
  identified when known.
- **Shots** — local and public provenance summaries with verification state.

Use the words `Private`, `Verified`, `Published`, and `App Store` for lifecycle
state. Keep raw cryptographic facts in an advanced inspector.

## Pair a device

Allow the user to scan a QR code or import a transport-neutral pairing request.
Show:

- which BuilderID the device is asking to join;
- a short public-key fingerprint;
- requested permissions;
- expiration;
- a human-readable warning when anything is invalid.

Approval must feel like one deliberate swipe-right action. The approval signs
the exact `AUTHORIZE_DEVICE` payload with an already authorized DeviceKey. No
secret moves between devices.

If the current installation is not an authorized Builder device, it may display
and verify the request but must not pretend it can approve it.

## Verify

Accept a Shot record, file, or QR payload and show deterministic checks for:

- record and schema;
- signature and authorized signer;
- ordered lineage;
- Apple Fascia;
- local source commitment when available;
- public witness when explicitly requested and network access is available.

The verifier must not call an LLM.

## Provenance

Show local and public provenance without displaying private prompts or app
data. Identify the first implementation as:

```text
JP / Anky, Inc.
jpfraneto.eth
```

This is creator provenance, never permission or contract authority.

## Apple behavior

- SwiftUI, iOS 17 or newer.
- No third-party package or runtime dependency.
- One useful screen within two seconds.
- Local-first persistence.
- App-specific P-256 InstallationKey in Secure Enclave/Keychain where
  available.
- No CloudKit requirement and no Apple ID protocol dependency.
- Network use is opt-in and declared by the Fascia.
- Respect Dynamic Type, VoiceOver, dark mode, Reduce Motion, and device size.

## Visual character

Use native Apple typography and restrained TOHSENO framing. Chemical Amber
marks a deliberate human authorization or publication action, not decoration.
The app's information should be quieter than the Shots it describes.

Include explicit empty, loading, success, failure, expired, offline, and
interrupted states.

## Acceptance

The app is accepted only when it is generated by the same path as another Shot,
contains the same Apple Fascia, builds, installs and launches on the connected
iPhone, records Evolution 1 with a valid signature, verifies locally, and does
not receive a special protocol or contract path.
