# Publish `tohseno@1.0.0`

Publication is a manual owner action. Do not publish until the immutable native
1.0.0 release exists and the official manifest is authorized and verified.

```sh
cd packages/cli
npm whoami
npm owner ls tohseno
npm view tohseno@0.0.2 --json
npm dist-tag ls tohseno
npm test
node test/pack-install.test.js
npm pack --dry-run
npm pack
tar -tzf tohseno-1.0.0.tgz
npm publish --access public
npm view tohseno@1.0.0 --json
npm dist-tag ls tohseno
```

Then verify without touching the global developer installation:

```sh
prefix="$(mktemp -d)/npm-prefix"
npm install --global --prefix "$prefix" tohseno@1.0.0
"$prefix/bin/tohseno" --help
"$prefix/bin/tohseno" --version
```

Only after the authorized native manifest exists, repeat on a genuinely clean
Mac user and run `tohseno install`, `tohseno doctor`, and `tohseno`. Do not
tag Git, create a GitHub release, or repin the public installer as part of npm
publication. This owner-authorized stable publication must leave `latest`
pointing to `1.0.0`, so the unversioned `npm i -g tohseno` command resolves to
the verified bootstrap.
