How it works

Build. Publish. Share. Verify.

Tohseno moves source and verifiable proof—not a binary signed by a stranger.

  1. 01Build on Mac

    Create or connect an Xcode project.

  2. 02Publish a Shot

    Approve the exact public release in Companion.

  3. 03Share one link

    Anyone can retrieve the exact source and proof.

  4. 04Verify and install

    Recipients build and sign for their own devices.

Requires macOS 14+, Xcode, an iPhone, and an Apple Account. Builders also use Tohseno Companion.
