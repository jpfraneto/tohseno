[ 001 / PERMISSION ]

Software can travel from one person to another without becoming a platform.

The builder ships exact source. The recipient’s Mac verifies it, builds it, signs it for their own Apple identity, and puts it on their iPhone.

[ 005 / OPEN SOURCE ]

is open.
The app

Tohseno is open source. You can inspect how it works, run the factory locally, and change it. Every app it creates is an ordinary SwiftUI project in its own Git repository. You decide whether to keep that app private or publish it.

[ 007 / BEFORE YOU INSTALL ]

One Mac app. Clear choices.

You need macOS 14 or later, Xcode, and an iPhone for phone installation. A free Apple Personal Team works for personal-device signing.

Bring a supported model subscription, connect an explicit local model endpoint, or approve a capped use of managed intelligence from a prepaid balance. Local creation stays available without a Tohseno subscription. Your app, source repository, and installed result remain yours.

[ 008 / PUBLIC REGISTRY ]

Discover apps.
Inspect the proof.

The Registry shows releases whose builder signature, content digest, transaction receipt, authorized DeviceKey, and Robinhood Chain checkpoint agreed at publication. The Mac checks fresh chain state before Install or Fork.
