TOHSENO / PRIVACY

Privacy notice

No TOHSENO account, analytics, or generated-app content backend. The factory runs locally; each app declares its own data behavior.

This website

tohseno.com serves static pages. It has no accounts, no forms, no cookies, no analytics, and no third-party browser resources. The server keeps standard operational request logs (route, status, timing) with no tracking identifiers.

The local factory

The installed factory sends no TOHSENO telemetry. The public installer verifies the immutable CLI, Apple identity helper, and protocol materials before installing them locally. Each Shot carries its own local history and signed protocol records.

TOHSENO Studio runs on the Mac and binds to 127.0.0.1. It opens through an owner-only temporary launcher and requires a private local browser session for every Shot read or mutation. Intentions, reference images, Shots, builds, and execution records are not uploaded to tohseno.com. Temporary browser uploads are removed after the local request finishes or fails safely.

Each Shot keeps its exact intention package, reference copies, feedback, and harness execution records inside gitignored .tohseno directories so the owner can move the complete Shot between their machines. Private input is not committed to the Shot’s Git history or written to centralized TOHSENO logs. After every coding-harness exit, the verifier independently compares the repository state and reports an accepted Evolution only when it passes the local gates. Anyone given the whole unfiltered Shot directory may also receive private material, so owners should inspect it before sharing an archive.

TOHSENO itself does not send creation input to a TOHSENO service. A coding agent selected by the owner can read that input to build the app; its provider is a separate trust boundary with its own account, privacy, and retention terms.

Apps built on these rails

Apps start from a neutral kernel with local, account-free defaults and no backend, analytics, writing, or identity assumption. Their manifest declares data, storage, network, identity, integrations, entitlements, and irreversible operations; an accepted app may therefore declare an owner-controlled or third-party service. TOHSENO itself operates no centralized content backend for generated apps and has no path for their users' content. Every app builds and runs without TOHSENO credentials.
