## The thread Tohseno keeps

```text
your intention → source on the Mac → Xcode checks → app on the iPhone
       ↑                                                    │
       └────────────────── the next honest change ──────────┘
```

The characters you meet in these pages each hold one part of that story: the Mac keeps the workshop local, the coding agent writes, Xcode inspects, Companion carries your intent, and the iPhone is where the result has to become real.

If you only want to use the product, stay in **Start here** and **Make & evolve**. The deeper architecture, protocol, and operations sections are there when you need to inspect the machinery.
